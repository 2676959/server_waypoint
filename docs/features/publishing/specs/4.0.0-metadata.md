> Share server waypoints with clickable chat and navigation. Add client markers, a manager and map sync, or connect servers through Velocity.

Use [the project description](../../../project-description.md) as the full Markdown body. Its screenshots and documentation links use the `4.0.0` GitHub ref. That ref must contain the release documentation and gallery before the description is saved publicly. The old `master` README describes the previous release.

Keep Modrinth's client and server requirements **optional**: server features work with vanilla clients, and the mod can also run on a client without a matching server. Explain the feature differences in the description. Keep the existing Modrinth management/utility categories and CurseForge Server Utility, Map and Information, and Utility & QoL categories unless a separate categorization change is intended.

CurseForge's project contains client/server **mods**. The shared description mentions Paper and Velocity, so retain a visible Modrinth download link for those plugins. Do not put plugin JARs into this CurseForge mod project.

The live Modrinth license URL currently points to the older `1.21` branch. When editing the project links, point it to `https://github.com/2676959/server_waypoint/blob/4.0.0/LICENSE`, keeping the MIT license identifier.

VoxelMap-Updated (`wkzK5379`) is optional on Modrinth only for targets pinning a matching `voxelmap_<loader>` property. The original CurseForge VoxelMap project is a different distribution; do not substitute it as a dependency. Map mods remain optional. Runtime dependencies of the map mods themselves must still be installed as required by their selected versions.

The Velocity plugin requires Java 25. Use each Minecraft platform's required Java version for clients and backends.
