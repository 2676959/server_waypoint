# Live game verification

The [reusable runner](../../../tools/live-game-test/README.md) rebuilds and launches production Minecraft clients for runtime mixin, map editor and save/reload checks. Its historical preset covers five Server Waypoint download-ranked versions per modded platform.

The runner keeps isolated worlds and evidence per attempt. See its runbook for prerequisites, CLI commands, scenario coverage and proof boundaries.
