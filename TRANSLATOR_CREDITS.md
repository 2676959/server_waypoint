## Community Translators

Thank you to the community translators who contributed translations to earlier versions of Server Waypoint. Their contributions remain credited in [`CREDITS.txt`](./CREDITS.txt).

Many translations in version 4.0.0 were generated by AI and may contain mistakes. These credits recognize earlier community contributions and do not imply that the listed contributors wrote or reviewed the AI-generated translations in 4.0.0.

Previous translation contributors are not responsible for errors in translations generated or rewritten by AI for version 4.0.0.

## Human verification checklist for 4.0.0

A checked entry means a human reviewer fluent in that language has reviewed both the [server translations](./common/src/main/resources/lang/) and the [client translations](./mods/src/main/resources/assets/server_waypoint/lang/) for version 4.0.0, including meaning, terminology, placeholders, and formatting. Earlier translation credits do not count as verification of the current files.

All entries start unchecked because no human verification has been recorded here. Unchecked means verification is not yet recorded, rather than that the translation is known to be incorrect.

- [ ] English (`en_us`)
- [ ] Simplified Chinese (`zh_cn`)
- [ ] Traditional Chinese (`zh_tw`)
- [ ] Traditional Chinese (Hong Kong) (`zh_hk`)
- [ ] Spanish (`es_es`)
- [ ] Hebrew (`he_il`)

When checking an entry, add the reviewer's name or handle, review date, and a link to the review pull request or reviewed commit on the same line. Record partial reviews with their scope and leave the entry unchecked until both translation files have been reviewed. If translations change after review, clear the affected entry until the changes have been reviewed by a human.

## Adding contributor credits

Translation contributors who would like to be credited can add themselves to [`CREDITS.txt`](./CREDITS.txt) in a pull request. If you do not have a GitHub account, you can contact me on Discord instead.

Credit format: `Preferred Name` followed by an optional link.

Credit pull request guidelines:

- Edit only [`CREDITS.txt`](./CREDITS.txt) unless a translation file also needs to be added or updated.
- For human verification updates, also update the checklist above with the review details.
- Add one credit per line under the `Translation contributors` section using the credit format above.
- Include the language or locale you contributed to in the pull request description.
- Use only a name, handle, or link that belongs to you and that you are comfortable publishing.
- Keep links relevant to your identity or translation work, such as a GitHub profile, website, or translation platform profile.
